# The LijOLo-Demo-Project

Dieses Projekt zeigt den Eimsatz von LiquiBase, jOOQ, Testcontainer und LocalStack auf der Service-Ebene. 

## Requirements

Um dsa Projekt erfolgreich auszuführen, sind folgende Lokale Installationen erforderlich:

* Java 21
* Docker
* Maven 3
* lijolo-model
